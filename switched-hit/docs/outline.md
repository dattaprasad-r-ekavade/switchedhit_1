# SwitchedHit - T20 Cricket Management Simulator

## 1. Project Structure

- **`app/`**: Next.js 13 app directory for core application logic.
- **`components/`**: Reusable React components (Shadcn UI).
- **`data/`**: Turso database schema, migrations, and seed data.
- **`lib/`**: Helper functions and utilities.
- **`public/`**: Static assets (images, fonts).
- **`styles/`**: Global styles and Tailwind CSS configuration.
- **`.env.local`**: Environment variables for database connection.
